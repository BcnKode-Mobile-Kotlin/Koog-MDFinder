# 🛠️ ¿Para qué sirven? El uso principal de los lenguajes

Si alguna vez te has preguntado por qué existen tantos, la respuesta es simple: cada uno es una herramienta especializada para un "trabajo" diferente. Aquí tienes sus roles principales:

---

## 1. C# (C-Sharp)
Es el pilar del ecosistema **Microsoft**. Su uso se divide en dos grandes mundos: el desarrollo de aplicaciones empresariales con **.NET** y, sobre todo, el desarrollo de videojuegos gracias al motor **Unity**. Si juegas a algo en tu móvil o PC, hay muchas probabilidades de que haya C# detrás.

## 2. Objective-C
Aunque Swift le está ganando terreno, Objective-C sigue siendo el lenguaje de "mantenimiento" por excelencia para **aplicaciones antiguas de iOS y macOS**. Muchas de las librerías fundamentales de Apple todavía están escritas en este lenguaje, por lo que sigue siendo vital para entender las tripas del iPhone.

## 3. Go (Golang)
Es el lenguaje de la **nube y la infraestructura**. Diseñado por Google para ser eficiente en sistemas distribuidos, es el motor detrás de herramientas masivas como **Docker y Kubernetes**. Se usa principalmente para crear servicios de backend que necesitan manejar millones de peticiones simultáneas sin despeinarse.

## 4. Fortran
No dejes que su edad te engañe: sigue siendo el rey indiscutible del **cálculo científico y la simulación física**. Si quieres predecir el clima, diseñar un cohete o simular fluidos complejos, Fortran sigue siendo más rápido que casi cualquier otro lenguaje gracias a lo optimizado que está para las matemáticas puras.

## 5. Kotlin
Es el lenguaje oficial y preferido para el **desarrollo de aplicaciones Android**. Ha sustituido a Java en la mayoría de los proyectos modernos gracias a que es más seguro y requiere menos líneas de código. También se está volviendo muy popular en el backend (lado del servidor) y en proyectos multiplataforma.

## 6. C++
Donde la **velocidad extrema** es innegociable, ahí está C++. Se usa para crear motores de videojuegos (como Unreal Engine), navegadores web (Chrome, Firefox), software de edición de vídeo y sistemas financieros de alta frecuencia donde cada microsegundo cuenta.

## 7. Python
Es la "navaja suiza" moderna. Aunque sirve para casi todo, sus reinos actuales son la **Inteligencia Artificial (IA), el análisis de datos y la ciencia**. También es muy querido por los investigadores y para automatizar tareas sencillas (scripts) debido a que se lee casi como el inglés.

## 8. COBOL
El lenguaje invisible que sostiene la economía mundial. Se usa casi exclusivamente en **sistemas bancarios, seguros y administración pública**. Si retiras dinero de un cajero automático, es muy probable que una línea de código COBOL escrita hace 40 años esté procesando tu transacción en un "mainframe".

## 9. C
Es el "lenguaje de los sistemas". Se usa para escribir **sistemas operativos** (como el kernel de Linux o Windows), controladores de hardware (drivers) y software para dispositivos empotrados (como el chip de tu microondas o el sensor de un coche). Es el lenguaje que habla directamente con los "hierros" de la computadora.

## 10. Java
El estándar de oro para el **software empresarial a gran escala**. Se usa en el backend de bancos, grandes plataformas de e-commerce y sistemas de gestión interna de multinacionales. Su gran ventaja es la estabilidad: un programa en Java escrito hace 15 años puede seguir funcionando hoy en casi cualquier servidor.

## 11. Swift
Es el lenguaje moderno y exclusivo para el **ecosistema Apple**. Si quieres crear una app nativa para iPhone, iPad, Mac o Apple Watch, Swift es tu herramienta. Es rápido, seguro y está diseñado para aprovechar al máximo el hardware de la manzana.

---

> **Resumen rápido:**
> * **¿Juegos?** C++ o C#.
> * **¿Apps de móvil?** Swift (iOS) o Kotlin (Android).
> * **¿Ciencia e IA?** Python o Fortran.
> * **¿Servidores y Nube?** Java o Go.
> * **¿Hardware y S.O.?** C.
> * **¿Bancos y legado?** COBOL.
